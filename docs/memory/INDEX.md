# Langzeitgedächtnis – LifeRoutine (Projekt)

Dieses Verzeichnis ist das **projektspezifische** Gedächtnis für Cursor/Auto.
Persönliches Gedächtnis über alle Projekte: `C:\cursor\memory\`

## Dateien

| Datei | Zweck |
|---|---|
| `decisions.md` | Getroffene Produkt-/UX-/Preisentscheidungen |
| `costs.md` | Infra-Kosten, Preisdeckung, später Strato-Umzug |
| `backlog.md` | Ideen, später, bewusst nicht jetzt |
| `domain.md` | Produktkonzept, IA, Module, Geschäftsmodell |
| `prototype.md` | Stand des UX-Prototyps |

## Quellen

- Maßgeblich: `docs/konzept/LifeRoutine_Konzept_V1.1_Dokumente_Fristen.pdf`
- Vorgänger: `docs/konzept/LifeRoutine_Konzept_V1.0.pdf`

## Regel für Agenten

1. Zu Session-Beginn relevante Dateien hier lesen (mindestens `decisions.md` + `domain.md`).
2. Neue stabile Erkenntnisse **sofort** hier ergänzen (nicht nur im Chat lassen).
3. Features nicht aufblasen — Backlog statt Sofortbau.
