LifeRoutine

Dein Alltag. Einfacher. — Funktionsstand & offene Punkte

Stand: 9. August 2026 · Prototyp: apps/prototype · lokal http://localhost:3001
Konzept: V1.1 · Schwestermarke zu AquaRoutine

Kurzfazit: Der lokale Prototyp deckt die Kernschleife Einkauf–Vorrat–Plan–Haushalt ab und ist als PWA installierbar. Noch nicht „Produkt für Kunden“: keine echten Live-Angebotsfeeds, kein Cloud-Sync/Login, kein Zahlungsabo. Angebotsprinzip: Prospekt verlinken + selbst markieren oder Demo — kein Scraping.

1. Was jetzt funktioniert

Start & Gerät

  • Onboarding: Name, Haushaltstyp, Ortssuche (Nominatim/OSM) + optional GPS
  • Persistenz lokal (localStorage)
  • PWA: Manifest, Icons, Service Worker, Install-Hinweis
  • Optionale App-PIN (lokal gehasht), Sperre nach Hintergrund
  • Datenschutz-Seite (Prinzipien, Löschen)

Heute

  • Prioritäten mit „Warum“, €-/Zeit-Nutzen, Verbund-Insights
  • Links zu Einstellungen / Haushalt

Einkauf

  • Liste: Tippen, Barcode (Katalog → Open Food Facts → merken), privat/geteilt, Erledigt → Vorrat
  • Angebote: Demo-Katalog (OfferProvider) + manuell „aus Prospekt markieren“; Badges Demo / Von dir
  • Route / Extraweg: aus gewählten Märkten + Angeboten
  • Märkte: Live OSM/Overpass am Standort; Auswahl speichern; Online-Prospekt-Links je Kette
  • Vorräte: Menge +/−, Einheit, Mindestvorrat; Beleg-OCR → Vorrat; „Nachkaufen lohnt“
  • Essensplan / Katalog / Angebote-Stub

Zuhause · Plan · LifeAI · Haushalt

  • Routinen (abhaken, neu anlegen)
  • Plan: 3-Tage-Überblick; Dokumente & Fristen (nur Metadaten, keine Ausweis-/Kartennummern)
  • LifeAI: regelbasierte Demo-Befehle (Liste/Routinen)
  • Haushalt: Mitglieder, Einladungs-Code (Demo gleicher Browser)

Einstellungen

  • Profil, Ort, Links zu Haushalt / Märkte / Katalog / Datenschutz / PWA-Install / PIN

2. Was noch gemacht werden muss

A) Damit die App sich „echt“ anfühlt (lokal, hohe Priorität)

  • Frisch-Start ohne Fake-€-Angebote (Ersparnis nur aus Nutzer-Markierungen / später Partner)
  • Heute stärker nur aus echten Nutzerdaten speisen
  • LifeAI ehrlich benennen oder sinnvoll ausbauen (kein Chatbot-Versprechen)
  • Backup: Export/Import der lokalen Daten
  • Farben / Brand finalisieren
  • Wetter: live oder klar als Demo kennzeichnen

B) Damit sie für Kunden funktioniert (Infrastruktur)

  • Kleiner Server / Backend
  • Login + echter Haushalt-Sync (mehrere Geräte)
  • HTTPS für zuverlässige PWA-Installation außer Heimnetz
  • Stripe (o. Ä.) für Abo-Zahlungen
  • Impressum / AGB / Datenschutzerklärung (Generator, nicht Copy-Paste fremder Firmen)
  • Gewerbe / Kleinunternehmer klären (außerhalb der App)

C) Echte Supermarkt-Angebote (strategisch)

  • Partner: Aggregatoren und/oder Ketten (Pilot-Feed) — Anschreiben
  • OfferProvider um „partner“ erweitern (UI ist vorbereitet)
  • Kein heimliches Prospekt-Scraping (ToS / Recht)
  • Zwischenlösung bleibt: Prospekt-Link + selbst markieren

D) Später / Vision

  • Besserer Barcode-Lookup, Beleg-Layouts, Preisverlauf
  • Autopilot höhere Stufen, Usability-Tests, Preismodell testen
  • Marke/Domain final, Kinder-Modus, Smart Home, Mobilität, …

4. Empfohlene Reihenfolge

  1. Lokal „echt“ machen (A): keine Fake-€, Backup, Brand
  2. Feedback mit 3–5 Testern (PWA aufs Handy)
  3. Anschreiben Aggregator/Kette (C)
  4. Backend + Login + Stripe (B), wenn Validierung passt
